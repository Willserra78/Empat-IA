# Empat-IA — IA Assistiva para Apoio Educacional

## Descrição curta

Projeto acadêmico desenvolvido em equipe para explorar o uso responsável de IA assistiva em contexto educacional, com foco em interação apoiada, supervisão humana, privacidade e cuidado ético.

## Objetivo

Investigar como modelos generativos podem apoiar a organização de interações, o acolhimento inicial e a orientação responsável em ambientes educacionais, sempre com controle humano e limites claros de uso.

## Contexto

O projeto foi desenvolvido em equipe, em contexto acadêmico, com William Serra atuando como líder técnico.

## O que o projeto demonstra

- Aplicação de IA generativa em contexto sensível.
- Integração entre interface, cloud e serviços de IA.
- Uso de Python, Streamlit e AWS Bedrock em protótipo educacional.
- Preocupação com privacidade, governança e responsabilidade ética.
- Trabalho colaborativo em equipe multidisciplinar.

## Tecnologias

- AWS Bedrock
- Python
- Streamlit
- Boto3
- JSON

## Cuidados e limitações

- Este projeto não realiza diagnóstico.
- Este projeto não substitui profissionais de educação, saúde, psicologia ou assistência especializada.
- A IA é apresentada como apoio inicial, organização de interação e sugestão assistida.
- Qualquer uso em contexto real exige supervisão humana, validação institucional, cuidado ético, privacidade e governança adequada.

## Enquadramento profissional

Empat-IA deve ser entendido como projeto acadêmico de IA assistiva para apoio educacional, com ênfase em responsabilidade ética, interação assistida, supervisão humana e uso responsável de modelos generativos.
